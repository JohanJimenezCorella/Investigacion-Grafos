# Grafos: BFS, DFS, Prim y Kruskal

Proyecto académico desarrollado en Java para la investigación de estructuras de datos y algoritmos de grafos.

El proyecto implementa los algoritmos de recorrido BFS y DFS, así como los algoritmos de árboles de expansión mínima Prim y Kruskal.

## Requisitos

- Java Development Kit (JDK) 8 o superior.
- Git para clonar el repositorio.

## Descargar el proyecto

Clonar el repositorio mediante el siguiente comando:

```bash
git clone https://github.com/JohanJimenezCorella/Investigacion-Grafos.git
```

Ingresar a la carpeta del proyecto:

```bash
cd Investigacion-Grafos
```

## Compilar y ejecutar

Desde la carpeta principal del proyecto, ejecutar los siguientes comandos:

**Compilar:**

```bash
javac src/Main.java
```

**Ejecutar:**

```bash
java -cp src Main
```

## Contenido

- **BFS:** recorrido en anchura utilizando una cola.
- **DFS:** recorrido en profundidad iterativo utilizando una pila.
- **Prim:** algoritmo de árbol o bosque de expansión mínima utilizando una cola de prioridad.
- **Kruskal:** algoritmo basado en el ordenamiento de aristas y la estructura Disjoint Set Union (Union-Find).

## Características del grafo

- Los vértices se identifican mediante enteros desde `0` hasta `V-1`.
- El grafo de ejemplo es no dirigido y ponderado.
- BFS y DFS realizan recorridos desde un vértice inicial.
- Prim y Kruskal permiten obtener árboles de expansión mínima en grafos conexos.
