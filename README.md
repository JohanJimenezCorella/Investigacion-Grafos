# Grafos: BFS, DFS, Prim y Kruskal

Proyecto académico en Java. Requiere JDK 8 o superior.

## Compilar y ejecutar
```bash
javac src/Main.java
java -cp src Main
```

## Contenido
- BFS: recorrido en anchura con cola.
- DFS: recorrido en profundidad iterativo con pila.
- Prim: árbol/ bosque de expansión mínima con cola de prioridad.
- Kruskal: ordenamiento de aristas y estructura Disjoint Set Union (Union-Find).

Los vértices se identifican con enteros de 0 a V-1. El grafo del ejemplo es no dirigido y ponderado.
